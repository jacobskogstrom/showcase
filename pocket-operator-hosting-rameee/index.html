3. Not in 48h: moving the bot backend off Hbot

Don't rush this one. The silo engine today runs 4 live family bots (marcus, malin, jacob-bengt, jacob-marcus) plus the slot pool for beta friends. Moving it means: porting PowerShell scheduled-task orchestration to Linux (systemd/cron), re-testing SOPS+age secret decryption on a new OS, re-authenticating the Claude Code CLI headless on the new box, and cutting over each live bot's Telegram webhook without dropping messages. That's a multi-day project done carefully at a desktop, not a Telegram-triggered 48h sprint — a botched cutover risks the family assistants going dark, not just the beta.

When you do it: recommended host

You asked specifically about German hosting — good instinct, and not just for the accent. This system reads and stores real user data (chat history, notes, on higher tiers Google account access), and the 07-10 design doc already flags GDPR/privacy review as an open item before widening past friends. An EU/German-jurisdiction host is the right default for that reason alone, independent of price.
